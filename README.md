# Описание

Этот репо - сборник всех моих конспектов, (в т.ч. перевод word доков в md в связи с чем могут встречаться ошибки/странности внутри файлов), который долгое время использовался как личное хранилище данных для синхронизации всех конспектов и заметок на всех своих устройствах через git

На данный момент он полностью открыт для просмотра и загрузки данных. Настоятельно рекомендуется использовать именно связку Obsidian + Git т.к. именно так он создавался и поддерживается мной на данный момент
# Как начать пользоваться

***Понадобится скачать [Obsidian](https://obsidian.md/download) и [Git](https://git-scm.com/book/ru/v2/%D0%92%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5-%D0%A3%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0-Git), если они еще не установлены***

## Если git еще не был установлен

1. После установки гита потребуется его быстрая начальная настройка. Открываем терминал и вводим эти две команды (они полностью универсальны для всех ОС)
```git
git config --global user.email Мой email
git config --global user.name Мое имя   
```
---

Первое, что потребуется сделать - клонировать репо в любую свободную папку с помощью `git clone <ссылка на этот репозиторий>` и дождаться полной загрузки файлов
