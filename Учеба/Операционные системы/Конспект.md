# Основы Linux
---

Linux это система дистрибутивов Unix-подобных ОС, кторое включает:
* Ядро
* Набор утилит и программ проекта GNU

Основные особенности Linux:
* Свободный доступ к исходному коду
* Право на модификацию
* Право на распространение
* Обязательство открытости исходного кода

Эти особенности и общая популярность приводят к следующим преимуществам:
* Быстрое обнаружение и исправление ошибок
* Мгновенное внедрение и использование новых технологий и функций
* Высокая стабильность ОС

`Линус уже не кодит сам, но учавствует в контроле качества ОС и архитектурных правках`

## Архитектура ядра Linux

Ядро - центральный диспетчерский пункт ОС. Это программа, которая всегда находится в памяти и работает в привилегированном режиме, и управляет всеми процессами, имеет доступ ко всему аппаратному обеспечению

### Функции ядра
* **Взаимодействие** с аппаратным обеспечением
	* Ядро с**одержит драйверы** устройств
	* Ядро "**переводит**" запросы в команды для железа (**кодирующее - декодирующее** устройство)
* **Распределение** оперативной памяти
	* Ядро решает **какое количество** памяти выделять процессам
	* **Реализация** виртуальной памяти
	* Для обработки файлов ядро **обращается к контроллеру памяти**
	* **Защита** памяти одного процесса от другого
* **Управление** процессами
	* **Создание** и **уничтожение** процессов
	* **Планирование** выполнения
	* **Взаимодействие** процессов между собой (межпроцессорное взаимодействие)
* Работа с **файловыми** системы
	* Предоставление **единого** интерфейса для работы с **различными** файловыми системами 
	* Работа с **кэшированием** для ускорения всей работы
	* Управлять **правами доступа** к этим файлам
* **Сетевое** взаимодействие
	* Реализация **сетевых протоколов**
	* Управление **сетевыми интерфейсами**
	* Обеспечение **сетевой безопасности**

### Ключевая особенность Linux
**Монолитное** ядро с поддержкой загружаемых **модулей**, что говорит о модульной архитектуре

**Монолитное ядро** - все основные компоненты работают в едином адресном пространстве, а прямые вызовы ф-ций будут происходить быстро из-за работы "напрямую"

**Модульность** позволяет добавлять функциональность **без перегрузки всей системы**, что экономит память (например очень легко обновлять дрова) и возможность загружать **только необходимые компоненты**

### Основные компоненты ядра Linux

1. Планировщик процессов (SCHED). Алгоритмы планировщика:
	1. CFS - алгоритм для **обычных** задач. Старается выдать им равное время
	2. Real Time Scheduler - алгоритм для задач в **реальном** времени (например обработка звука в видео) 
	3. Deadline scheduler - для задач с жесткими временными **ограничениями**
2. Менеджер памяти (MM)
	1. Выделение памяти процессу по запросу
	2. Освобождение памяти при завершении
	3. Виртуальная память. Если просто, каждый процесс считает, что у него есть вся память системы, но на самом деле ядро транслирует ему память и выделяет виртуальную либо реальную память. Это нужно для изоляции процессов друг от друга
	4. Перемещение неиспользуемых страниц в памяти на диск
	5. Кэширование
3. Виртуальная файловая система (VFS). Это абстрактный слой, скрывающий различия между файловыми системами. 
	1. Файловые системы:
		1. Ext4 - основная для **Linux**
		2. NTFS - файловая система **Windows**
		3. FAT32 - **флешки** (флеш-память)
		4. NFS - **сетевая** файловая система
		5. tmpfs - память **системы**
4. Сетевые интерфейсы (NET)
5. Межпроцессорное взаимодействие (IPC). Механизм обмена данными между процессами
	1. Сигналы - асинхронные уведомления
	2. Каналы - однонаправленная передача данных
	3. Сокеты - двунаправленная связь
	4. Разделяемая память - самый быстрый способ обмена большими объемами данных
	5. Очереди сообщений - асинхронная передача структурированных данных
	6. Семафоры - синхронизация доступа к ресурсам

# Дистрибутивы Linux
---
## Классификация дистрибутивов Linux

Для работающей системы помимо ядра нужно:
1. Загрузчик (GRUB)
2. Системные утилиты
3. Графический интерфейс
4. Приложения
5. Система управления пакетами
6. Документация

**Дистрибутив** - готовая к установке сборка необходимого

1. Классификация по области применения
	1. Дистрибутивы **общего** назначения (для повседневного использования). Например: Ubuntu, Linux Mint, Fedora и д.р.
	2. **Серверные** дистрибутивы (для серверного использования). Например: Red Hat Enterprise Linux, Cent OS, Ubuntu Server и т.д.
	3. Дистрибутивы для **разработчиков**. Например: Fedora Workstation, Arch Linux
	4. Дистрибутивы для **безопасности**. Например: Kali Linux, Parot Security OS
	5. **Мобильные** дистрибутивы для смартфонов, планшетов и т.д. Например: Android, Ubuntu Touch
	6. **Встраиваемые** системы. Используются для умных устройств, роутеров и т.д. Например OpenWrt, Buildroot, RouterBoard
	7. **Научные** дистрибутивы. Например: MATLAB - подобные среды, статистические пакеты, инструменты для моделирования, библиотеки для численных расчетов

## Состав дистрибутивов

1. Ядро Linux. Находится в /boot/ и называется vmlinuz - версия (у меня текущая - vmlinuz-6.8.0-94-generic). Оно может быть:
	1. Универсальным - generic
	2. Уникальным - custom
2. Программы начальной инициализации. Запускаются до загрузки основной системы:
	1. Загрузчик (GRUB). Показывает меню выбора ОС и загружает ядро
	2. initramfs - минимальная файловая система. Содержит в себе базовые драйверы для загрузки основной системы
	3. Система инициализации (systemd / sysd). Это первый процесс, который запускает все остальные службы
3. Программа установки (installer). Это программа, которая: 
	1. разбивает диск на разделы

	3. копирует файлы системы
	4. настраивает загрузчик
	5. создание пользователя
	6. настройка сети
