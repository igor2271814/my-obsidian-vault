## №1 Исследовать ряд на сходимость

$$
\sum_{n = 2}^{\infty}\frac{1}{n^{2} - n}
$$

**Решение:**

1. Раскладываем знаменатель: $n^{2} - n = n(n - 1)$. Таким образом, каждый член ряда: $a_{n} = \frac{1}{n(n - 1)}$.
2. Представляем дробь через разложение на простейшие: $\frac{1}{n(n - 1)} = \frac{1}{n - 1} - \frac{1}{n}$.
3. Ряд имеет вид: $\sum_{n = 2}^{\infty}\left( \frac{1}{n - 1} - \frac{1}{n} \right)$.
4. Это телескопический ряд, в котором большинство членов сокращается: $\sum_{n = 2}^{\infty}\left( \frac{1}{n - 1} - \frac{1}{n} \right) = 1$.
5. Вывод: ряд **сходится**, так как его частичная сумма имеет конечный предел.

## №2 Исследовать ряд на сходимость

$$
\sum_{n = 2}^{\infty}\frac{1}{\sqrt{n^{7} - 3}}
$$

**Решение:**

1. Упростим асимптотическое поведение знаменателя при больших $n$: $\sqrt{n^{7} - 3} \sim \sqrt{n^{7}} = n^{7/2}$. Таким образом, $a_{n} \sim \frac{1}{n^{7/2}}$.
2. Сравним данный ряд с $p$-рядом $\sum\frac{1}{n^{p}}$, где $p = 7/2 > 1$. $p$-ряд сходится.
3. По признаку сравнения, исходный ряд также **сходится**.

## №3 Исследовать ряд на сходимость

$$
\sum_{n = 20}^{\infty}\frac{1}{(n - 9)n}
$$

**Решение:**

1. Для $n \gg 9$ знаменатель можно упростить: $(n - 9)n \sim n^{2}$.
2. Тогда каждый член ряда: $a_{n} \sim \frac{1}{n^{2}}$.
3. Сравним с $p$-рядом $\sum\frac{1}{n^{p}}$, где $p = 2 > 1$. $p$-ряд сходится.
4. По признаку сравнения, исходный ряд также **сходится**.

## №4 Исследовать ряд на сходимость

$$
\sum_{n = 0}^{\infty}\frac{n}{n!}
$$

**Решение:**

1. Исходный ряд: $a_{n} = \frac{n}{n!}$.
2. Применим признак сравнения с рядом $\sum\frac{1}{n!}$, который известно, что сходится ($\sum\frac{1}{n!} = e$).
3. Члены $\frac{n}{n!}$ уменьшаются быстрее, чем $\frac{1}{n!}$. Следовательно, ряд **сходится**.
4. Проверим признак Даламбера: $\lim_{n \rightarrow \infty}\frac{a_{n + 1}}{a_{n}} = \lim_{n \rightarrow \infty}\frac{(n + 1)}{(n + 1)!} \cdot \frac{n!}{n} = \lim_{n \rightarrow \infty}\frac{1}{n + 1} = 0$.
5. Вывод: ряд **сходится**.

## №5 Исследовать ряд на сходимость (абсолютную и условную)

$$
\sum_{n = 1}^{\infty}\frac{( - 1)^{n}}{n^{2} + 1}
$$

**Решение:**

1. Исходный ряд: $a_{n} = \frac{( - 1)^{n}}{n^{2} + 1}$.
2. Проверим абсолютную сходимость:
   - Исследуем $\sum_{n = 1}^{\infty}\left| a_{n} \right| = \sum_{n = 1}^{\infty}\frac{1}{n^{2} + 1}$.
   - Сравним с $p$-рядом $\sum\frac{1}{n^{2}}$, который сходится ($p = 2 > 1$).
   - По признаку сравнения, ряд **абсолютно сходится**.
3. Проверка условной сходимости:
   - Если ряд абсолютно сходится, то он условно сходится автоматически.
4. **Вывод**: ряд **абсолютно и условно сходится**.

## №8 Исследовать ряд на сходимость (абсолютную и условную)

$$
\sum_{n = 1}^{\infty}\frac{( - 1)^{n}n!}{(2n)!}
$$

**Решение:**

1. Исходный ряд: $a_{n} = \frac{( - 1)^{n}n!}{(2n)!}$.
2. Проверим абсолютную сходимость:
   - Исследуем $\sum_{n = 1}^{\infty}\left| a_{n} \right| = \sum_{n = 1}^{\infty}\frac{n!}{(2n)!}$.
   - Применим признак Даламбера: $\lim_{n \rightarrow \infty}\left| \frac{a_{n + 1}}{a_{n}} \right| = \lim_{n \rightarrow \infty}\frac{(n + 1)!}{\left( 2(n + 1) \right)!} \cdot \frac{(2n)!}{n!} = \lim_{n \rightarrow \infty}\frac{n + 1}{(2n + 2)(2n + 1)} = 0$.
   - По признаку Даламбера, ряд **абсолютно сходится**.
3. Проверка условной сходимости:
   - Если ряд абсолютно сходится, то он условно сходится автоматически.
4. **Вывод**: ряд **абсолютно и условно сходится**.

## №9 Найти область сходимости функционального ряда

$$
\sum_{n = 1}^{\infty}\frac{1}{\ln^{n}x}
$$

**Решение:**

1. Это геометрический ряд с суммой: $S = \frac{1}{1 - \frac{1}{\ln x}}$, при условии $\left| \frac{1}{\ln x} \right| < 1$.
2. Решим неравенство: $\left| \frac{1}{\ln x} \right| < 1 \Rightarrow \left| \ln x \right| > 1$.
3. Решение неравенства:
   - $\ln x > 1 \Rightarrow x > e$.
   - $\ln x < - 1 \Rightarrow x < \frac{1}{e}$.
4. **Вывод**: область сходимости: $x \in \left( 0,\frac{1}{e} \right) \cup (e,\infty)$.

## №10 Найти область сходимости функционального ряда

$$
\sum_{n = 1}^{\infty}x^{(n - 1)}n^{100}
$$

**Решение:**

1. Применим признак Даламбера: $\lim_{n \rightarrow \infty}\left| \frac{a_{n + 1}}{a_{n}} \right| = \lim_{n \rightarrow \infty}\left| \frac{x^{n}(n + 1)^{100}}{x^{n - 1}n^{100}} \right| = \lim_{n \rightarrow \infty}|x|\left( \frac{n + 1}{n} \right)^{100} = |x|$.
2. Ряд сходится, если $|x| < 1$.
3. Проверка на краях:
   - При $x = 1$: $\sum n^{100}$ расходится.
   - При $x = - 1$: $\sum( - 1)^{n - 1}n^{100}$ расходится.
4. **Вывод**: область сходимости: $|x| < 1$.

## №11 Найти область сходимости функционального ряда

$$
\sum_{n = 1}^{\infty}\frac{x^{3(n - 1)}}{10^{n}}
$$

**Решение:**

1. Применим признак Даламбера: $\lim_{n \rightarrow \infty}\left| \frac{a_{n + 1}}{a_{n}} \right| = \lim_{n \rightarrow \infty}\left| \frac{x^{3n}}{10^{n + 1}} \cdot \frac{10^{n}}{x^{3(n - 1)}} \right| = \lim_{n \rightarrow \infty}\left| \frac{x^{3}}{10} \right| = \frac{|x|^{3}}{10}$.
2. Ряд сходится, если $\frac{|x|^{3}}{10} < 1$, то есть $|x| < \sqrt[3]{10}$.
3. Проверка на краях:
   - При $|x| = \sqrt[3]{10}$: $\sum\frac{\left( \sqrt[3]{10} \right)^{3(n - 1)}}{10^{n}} = \sum\frac{10^{n - 1}}{10^{n}} = \sum\frac{1}{10}$ расходится.
4. **Вывод**: область сходимости: $|x| < \sqrt[3]{10}$.
