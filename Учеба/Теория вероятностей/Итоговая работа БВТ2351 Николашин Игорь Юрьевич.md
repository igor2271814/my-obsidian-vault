**Условие:**  
Сообщение передается до первого правильного приема. Вероятность правильного приема каждого сообщения _p_=0,6. Найти вероятности событий:

- _A_={сообщение было передано хотя бы три раза};
- _B_={сообщение надо передавать третий раз}.

**Решение:**

1. Событие _A_:  
    Чтобы сообщение было передано хотя бы три раза, первые два раза должны быть неудачными:

_P_(_A_)=(1−_p_)2=(0,4)2=0,16

2. Событие _B_:  
    Сообщение нужно передавать третий раз, если первые два раза были неудачными, а третий — успешным:

_P_(_B_)=(1−_p_)2⋅_p_=(0,4)2⋅0,6=0,096

## Задание 4

**Условие:**

Вероятность попадания нормально распределенной случайной величины с математическим ожиданием   в интервал (4; 6) равна 0,8. Найти дисперсии данной случайной величины

**Решение:**

Из стандартной нормальной таблицы:  
P(−z < Z < z) = 0.8 → z ≈ 1.28  
=> σ = (6 − 4) / (2 * 1.28) = 2 / 2.56 = 0.78125  
=> σ² = 0.78125² ≈ 0.6104

Ответ: Дисперсия σ² ≈ 0.6104
