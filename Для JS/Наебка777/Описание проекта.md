- N различных игр. Планируется:
	- ***Угадай множитель.*** Состоит из трех игр
		- 1. ***Два*** числа, по сути подброс монетки - 1; 2 - увеличивает ставку в **два** раза
		- 2. ***Три*** числа - 1; 2; 3 - увеличивает ставку в **три** раза
		- 3. ***Четыре*** числа - 1; 2; 3; 4 - увеличивает ставку в **четыре** раза
		- 4. ***Пять*** чисел - 1; 2; 3; 4; 5 - увеличивает ставку в **пять** раз
	- ***Coin crash.*** Суть проста, рисуется график с положительными осями абсцисс и ординат, на нем постепенно увеличивается число N. Это число неотрицательное, нецелое и ***$N >= 1$***. Пользователь делает ставку и загадывает число. Если оно **$<= N$** тогда пользователь выигрывает и умножает свою ставку на свое число
	- ***Слоты.*** Цель проста, есть три числа/объекта, которые должны сойтись в единый ряд из одинаковых элементов. Будет делаться из трех вертикальных слайдеров. К каждому изображению в слайдере должен быть привязан символ, отвечающий за свое изображение. Для слотов из трех слайдеров только одна выигрышная комбинация - три одинаковых символа в ряду
- **Все** игры должны быть на одной странице с полным доступом к ним и не усложненным интерфейсом. К каждой важной функции либо div должен быть комментарий
